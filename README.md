# FDR 2.0

FDR 2.0 是面向 Windows 与 Linux 的游戏库和下载管理应用。你可以离线浏览随应用附带的游戏目录；下载游戏和检查在线目录更新需要网络。

当前正式版本：**2.0.0**。从 [2.0.0 发行页面](https://github.com/Frog-Symphony/FDR-2.0-releases/releases/tag/v2.0.0) 下载 Windows 10/11 x64 便携 ZIP。Linux 工作暂缓，本次未发布 Linux 包。旧 alpha 预览资源保留在历史发行列表。

## 快速开始

1. 下载 `FDR-2.0.0-windows-x64.zip` 并解压到本地目录。
2. 启动 `FDR.exe`。
3. 首次启动即可浏览随包目录。下载、在线目录更新及封面或元数据刷新需要网络连接。

无需运行安装程序。游戏文件默认下载到应用可执行文件同级的 `Downloads` 目录；可在应用设置中更改。

## 当前功能

2.0.0 已接入游戏目录浏览、分类和元数据展示、下载任务管理、自动解压选项、个人游戏库、Steam 与桌面快捷方式、游玩时长、云存档原型及本机数据备份。部分功能仍在开发和验收中，实际可用范围以应用内行为为准。

Windows 10/11 x64 是当前主要测试环境。Linux x64 压缩包以 CachyOS／Arch 为目标，尚待对应桌面环境实机验收。干净 Windows 环境、真实游戏下载、云存档远端传输和部分跨平台功能也仍在验证。

## 游戏目录

首次下载后，随包基础目录可离线浏览。客户端联网后会检查目录更新，并只获取版本变化所需的数据；目录快照、增量和修复分片由公开页面提供：

- [当前目录版本与更新清单](https://frog-symphony.github.io/FDR-2.0-releases/latest.json)
- [目录发布页](https://frog-symphony.github.io/FDR-2.0-releases/)

## 项目范围

本仓库用于发布应用压缩包和客户端目录数据，不包含应用源码。源码仓库保持私有。

## 客户端更新与版本

设置中的“客户端更新”会检查公开更新通道：成功检查且没有更高版本时显示“没有新版本”，网络或清单错误显示具体原因。下载完成后由用户确认退出并更新；游戏目录更新与程序更新独立。

后续采用语义化版本：兼容修复递增 PATCH（2.0.1），兼容新功能递增 MINOR（2.1.0），破坏兼容的变更递增 MAJOR（3.0.0）。已发布版本和资源不覆写。

已有 2.0 本地预览用户请先备份 `UserData`，再替换程序文件；旧 FDR 的代码和个人数据不迁移。
