# FDR

**从发现游戏，到下载、整理和启动，让你的游戏收藏有一个统一的入口。**

FDR 是面向中文用户的桌面游戏目录、下载管理与个人游戏库应用。你可以浏览随包附带的离线目录，查看游戏资料、收藏感兴趣的作品，管理下载和安装，再把已安装游戏整理到自己的游戏库中。

这是 FDR 2.0 重构项目的**公开发行仓库**，提供客户端、发行说明和在线目录数据。应用源码目前保持私有。本项目从零重构旧 FDR，不迁移旧版个人数据。

[下载最新正式版](https://github.com/Frog-Symphony/FDR-2.0-releases/releases/latest) · [全部版本与更新记录](https://github.com/Frog-Symphony/FDR-2.0-releases/releases) · [在线目录发布页](https://frog-symphony.github.io/FDR-2.0-releases/)

## FDR 能做什么

| 功能 | 使用方式 |
| --- | --- |
| **发现与收藏** | 浏览目录，通过搜索和分类寻找作品，查看封面、体积、语种等资料，收藏感兴趣的游戏。缺失资料保留未知状态，并持续补充。 |
| **下载与安装** | 从支持的外部来源创建任务，查看进度、暂停、继续和重试；配置下载目录与自动解压，支持 ZIP、7z 和 RAR。来源可达性与续传能力取决于实际服务。 |
| **个人游戏库** | 整理已安装游戏，以卡带、列表或图标视图浏览，设置启动文件、启动游戏并查看 FDR 记录的游玩时长。 |
| **桌面与 Steam 整合** | 为游戏创建或管理快捷方式，将常用游戏纳入已有的启动习惯。桌面快捷方式自动创建由用户主动开启。 |
| **数据与存档备份** | 创建和检查本地备份，恢复应用数据；将已明确配置的游戏存档纳入备份，恢复时确认目标位置和冲突处理。 |
| **天翼云盘接入** | 提供账号登录、分享文件下载、云存档和云备份入口。真实账号传输与远端恢复仍在验证，详见下方支持范围。 |
| **个性化设置** | 调整下载、窗口、网络与代理、启动音效和动态效果。应用内“减少动态效果”开关控制界面动效。 |

FDR 管理目录、任务和你的本机游戏库。游戏文件从对应外部来源下载，不由本发行仓库托管或中转。

## 下载与开始使用

### 支持的平台

| 平台 | 当前状态 |
| --- | --- |
| **Windows 10 / 11 x64** | 当前正式发行与主要验证平台，提供便携 ZIP。 |
| **Linux x64** | 项目目标平台，相关工作暂缓；历史测试包不代表当前正式支持，CachyOS／Arch 实机验收尚未完成。 |

具体版本的系统要求、已知问题和验证范围以对应 [Release 发行说明](https://github.com/Frog-Symphony/FDR-2.0-releases/releases)为准。

### 第一次运行

1. 打开[最新正式版](https://github.com/Frog-Symphony/FDR-2.0-releases/releases/latest)，在 **Assets** 中下载 `FDR-<版本号>-windows-x64.zip` 完整包。
2. 将 ZIP 完整解压到一个可写的本地目录，再运行其中的 `FDR.exe`。不要直接在压缩包预览中启动。
3. 在“全部游戏”中浏览、搜索或收藏作品；下载前确认来源、保存位置和空间需求。
4. 安装完成后，在“我的游戏”中检查启动文件，即可从个人库启动。
5. 按需调整下载、自动解压、窗口和动态效果设置；使用存档备份前，先确认每款游戏的存档目录。

无需运行安装程序，也不需要为了首次浏览目录配置开发环境。

> Release 中的 `*-delta.zip` 供客户端更新器使用，不能作为首次安装包直接解压运行。

## 两种独立的更新

### 客户端更新

在 **设置 → 客户端更新** 中检查新版本，阅读发行说明并下载。下载完成后，由你确认“退出并更新”，客户端再替换程序文件并重新启动。

满足基准条件时使用增量包，仅传输变化文件；其它情况使用完整包。成功检查后没有更高版本才表示已是最新，网络或更新清单错误会单独提示原因。

更新保留 `UserData` 和 `Downloads`，仍建议提前做好数据备份。版本采用语义化版本号：修复递增 PATCH、兼容的新能力递增 MINOR、不兼容变更递增 MAJOR。具体改动放在 Release 中，已发布版本和资源不覆写。

不具备更新器的历史版本请下载最新完整包。手动替换前关闭 FDR 并备份用户数据，不要删除原有 `UserData` 或游戏目录。

### 游戏目录更新

目录数据与客户端版本独立。首次运行可以浏览随包基础目录，联网后可检查新资料；版本变化时按需要获取快照、增量或修复分片，无需为了目录变化重新下载整个客户端。

- [在线目录发布页](https://frog-symphony.github.io/FDR-2.0-releases/)
- [目录版本清单](https://frog-symphony.github.io/FDR-2.0-releases/latest.json)

目录来自外部来源，并持续补充封面、中文标题和语种等资料。收录数量、来源内容与链接可用性会变化；条目出现在目录中，不等于下载来源始终可用，也不代表所有资料已完整核验。

## 数据放在哪里

| 内容 | 默认位置与说明 |
| --- | --- |
| **应用数据** | 程序目录中的 `UserData`，包含设置、个人库、任务记录、游玩记录和目录缓存等。 |
| **下载文件** | 程序目录中的 `Downloads`，可在设置中更改；修改设置不移动已有任务的文件。 |
| **游戏安装与存档** | 以实际安装位置及每款游戏配置的存档目录为准，不一定在程序目录内。 |
| **本地备份** | 用户选择的位置。可包含应用数据和已配置的存档，不包含游戏安装文件及下载压缩包。 |
| **云账号会话** | 存放在系统凭据库，不随本地备份导出；跨设备使用需要重新登录。 |

保留程序目录不等于备份了所有游戏存档。移动 FDR、游戏目录或更换电脑后，请检查安装路径和存档配置，必要时在个人库中重新关联游戏。

## 当前支持范围

FDR 持续开发中，功能入口与已完成真实环境验收的能力并不完全等同。

- **Windows 已验证流程**包括目录浏览、个人库与界面交互、本地备份相关流程，以及客户端公网下载升级、健康重启和用户数据保留。各版本的验证记录与限制见发行说明。
- **游戏下载**依赖外部站点、账号状态及网络条件。部分真实样本已验证，大型游戏传输、长期续传和来源协议变化仍需继续验证。
- **天翼云盘与云功能**已接入，但真实账号上传、下载和完整远端恢复仍在验证；请保留可用的本地备份。
- **存档位置发现**提供候选并要求用户确认，不能覆盖所有游戏，也不会仅凭相似名称自动备份其它目录。
- **Linux、真实硬件手柄与屏幕阅读器**尚未完成正式环境验收。中国大陆不同网络下的封面和外部来源可达性仍需持续观察。

## 常见问题

**离线能用吗？**

可以浏览已有目录和本机个人库。新封面、资料刷新、下载、云功能和在线更新需要网络；游戏本身是否需要联网由游戏决定。

**旧 FDR 的数据能直接导入吗？**

目前不支持。FDR 2.0 是重新实现的项目，不迁移旧版个人数据。

**为什么下载停在等待链接，或者封面加载失败？**

外部来源可能限流、链接过期、登录失效或网络不可达。先查看具体错误，检查网络与代理设置；需要登录的来源可重新检查账号状态。网络失败不表示游戏文件已下载完成。

**应用数据备份会保存整个游戏吗？**

不会。它保护应用数据及已配置的存档，游戏安装文件和下载压缩包需要另行保留。

**为什么系统关闭动画后，FDR 仍有动画？**

FDR 的动效由应用内“减少动态效果”开关控制。需要静态界面时请在 FDR 设置中开启该选项；启动音效使用独立开关。

## 反馈问题

遇到问题或有建议，可在 [Issues](https://github.com/Frog-Symphony/FDR-2.0-releases/issues) 中反馈；提交前可以先搜索是否已有同类报告。

反馈时请提供客户端版本、操作系统、复现步骤、预期结果与实际结果；涉及下载时，可补充游戏名称、来源类型和应用显示的错误。截图或相关日志有助于定位问题。

发布截图和日志前，请移除账号凭据、提取码、带签名的下载链接及个人路径等敏感信息。公开发行与已知问题以本仓库 [Release 页面](https://github.com/Frog-Symphony/FDR-2.0-releases/releases)为准。
